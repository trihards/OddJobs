# Odd Jobs

A playful library of tiny service-work minigame prototypes. **This is a test kitchen, not the integrated game.**

## Play
Open `index.html` through GitHub Pages to browse the current prototypes. Each minigame is its own standalone HTML file, so it can also be opened directly.

## Locations
- **Perks:** espresso, latte art, tea blending, table cleaning, pour-over.
- **Lane 7:** shoe counter, ball polishing, arcade jam clearing, Last Call.
- **The Bookshop:** shelf service, book seek, cover story, page rescue.
- **Roadside Stop:** snack packing, windshield cleaning, oil checking.

## Principles
- Make the toys fun before building the town or character systems.
- Respect the skill and care in often-overlooked service work.
- Let players make mistakes; don't block imperfect choices. Make outcomes visible.
- Prefer tactile actions and in-world feedback over instructions, meters, and repeated confirmation screens.
- Don't add timers when they don't serve the mechanic.
- Keep individual prototypes separate; later work may add a finite shift structure, optional help, visual/audio continuity, impatient customers, and character loadout effects.
- No runtime build tools required for this prototype gallery.

## Publishing
For this public repository, GitHub Pages can serve the root directory of the `main` branch. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`, and Save (one-time setup).

## Development
Prototype source files live in `games/` grouped by venue. Retain the originals and keep future changes small and testable. See `DESIGN_NOTES.md` for the playtest decisions.
